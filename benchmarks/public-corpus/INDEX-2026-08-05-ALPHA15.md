## Reproduce locally

Prepare clean local checkouts at the commits in `manifest-scope.tsv`, then run:

```bash
PYTHONPATH=src python3 tools/run_public_corpus.py /path/to/corpus \
  --manifest benchmarks/public-corpus/manifest-scope.tsv \
  --output-dir /private/path/to/normalized

python3 tools/generate_assurance_index.py \
  --summary /private/path/to/normalized/summary.json \
  --manifest benchmarks/public-corpus/manifest-scope.tsv \
  --output-dir /private/path/to/public-index
```

Do not add the normalized output or raw reports to a public repository without
the review and disclosure process described in the corpus publication gate.
