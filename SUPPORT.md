# Support

PgExtAssure is an open-source project maintained on a best-effort basis.
Commercial support and response-time guarantees are not currently offered.

## Questions, bugs, and feature requests

Open an issue at:

<https://github.com/borborich/pgextassure/issues>

Before filing a bug, use the latest release and search existing issues. Include:

- the PgExtAssure version or commit;
- the command and non-sensitive arguments used;
- the operating system and Python version;
- the smallest public reproduction you can provide;
- expected behavior and complete error output.

Reports may contain filenames, line numbers, and source excerpts. Redact private
source, credentials, tokens, and customer data before posting.

For private vulnerability reports, follow [SECURITY.md](SECURITY.md). Questions
about findings in a third-party extension should also be discussed with that
extension's maintainers, who understand its intended privilege and deployment
model.
